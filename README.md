# StockFlow Dashboard

Create a professional, clean, modern, responsive ERP Stock Management System frontend. Include a login page and an admin dashboard with navigation and structured screens for Dashboard, Product Management, Supplier Management, Customer Management, Purchase Management, Sales Management, Current Stock Management, Stock In/Stock Out History, and Reports. Build only the frontend structure and navigation for now. Do not add dummy database data or connect any database; Firebase Firestore will be connected later.
